## Теоретические сведения

Структурное программирование строит алгоритм из следования, ветвления и
повторения. В программе следование задаёт порядок вычислений, `if/elif/else`
выбирает действие, `for` перебирает числа или символы, а `while` повторяет
операции до выполнения условия завершения. Функции получают аргументы и
возвращают результат через `return`. Вычисления отделены от ввода и вывода,
поэтому их можно проверять независимо от консольного интерфейса.

В работе используются целые числа `int`, строки `str`, логические условия,
кортежи для перестановки значений и множество гласных для проверки вхождения.
Пакет `lab2` содержит модуль `algorithms.py`. При импорте модуля вычисления
и ввод данных не запускаются: точка входа защищена условием
`if __name__ == "__main__"` в `main.py`.

## Ход выполнения

### Сумма нечётных чисел

Под «до N» принято включение верхней границы: суммируются положительные
нечётные числа от 1 до N включительно. N — целое неотрицательное число.
Цикл `for number in range(1, n + 1, 2)` добавляет только нечётные значения.
При N=10: 1+3+5+7+9=25; при N=9 результат также 25.
При N=0 сумма пустой последовательности равна 0; отрицательное N отклоняется.
Временная сложность O(N), дополнительная память O(1).

### НОД перебором делителей

Для среднего задания реализован отдельный алгоритм `gcd_basic`.
После взятия модулей чисел перебор начинается с меньшего числа и идёт вниз.
Первое число, делящее оба аргумента без остатка, является наибольшим общим
делителем. Для 48 и 18 ответ 6. Если один аргумент равен нулю, возвращается
модуль другого. Для пары (0,0) принято программное соглашение: результат 0.
В худшем случае выполняется O(min(|a|,|b|)) проверок, память O(1).

### Подсчёт гласных

Строка приводится к нижнему регистру. Каждый символ сравнивается с множеством
`аеёиоуыэюяaeiou`; счётчик увеличивается для каждого вхождения, включая повторы.
Русская «ё» учитывается; английская `y` по принятому правилу не учитывается.
Пробелы, цифры и знаки препинания пропускаются. Пустая строка даёт 0.
Примеры: «Привет, мир!» → 3; «Hello, Python!» → 3.
Время O(L), где L — длина строки. `lower()` создаёт копию строки, поэтому
дополнительная память этой реализации составляет O(L).

### Алгоритм Евклида

Для повышенного задания реализована функция `gcd_euclid`.
Используется равенство НОД(a,b)=НОД(b,a mod b). Пока b не равен нулю,
выполняется `a, b = b, a % b`. Ненулевой остаток меньше предыдущего делителя,
поэтому цикл завершается. Последнее значение a — искомый НОД.

Для (48,18) последовательность пар: (48,18) → (18,12) → (12,6) → (6,0).
Результат 6. Знаки и нули обрабатываются так же, как в `gcd_basic`.
Для ненулевых аргументов число итераций — O(log(min(|a|,|b|))), память O(1)
в модели фиксированной стоимости арифметических операций.
В прикладных функциях `math.gcd` не используется; в тестах он служит
независимым эталоном для сравнения результатов двух реализаций.

### Собственный модуль и импорт

Четыре функции находятся в `lab2/algorithms.py`. Файл `main.py` импортирует
их через `from lab2.algorithms import (...)` и вызывает в ветках команд.
Таким образом модуль используется реально, а не только присутствует в папке.
Общая валидация вынесена в служебную функцию `_require_integer`.
Аннотации типов и краткие docstring описывают назначение функций.
